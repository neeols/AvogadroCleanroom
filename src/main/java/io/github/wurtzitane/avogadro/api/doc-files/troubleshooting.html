Fix a missing or incorrect preview

Check the source, the loaded definition, and the association in that order. The log normally names the rejected file or operation.

An index error, corrected

{"atoms":[{"e":"H","x":0,"y":0,"z":0},{"e":"H","x":0.74,"y":0,"z":0}],"bonds":[[0,1]]}

Only indices 0 and 1 exist. A bond [0,2] would be rejected. Use an ordinary formula H2 if supplying one; the labels draw subscripts for you.

Reload the source you edited

/avogadro reload reloads common server sources and syncs connected clients; it needs permission level 2. F3+T refreshes client resources and local files. Java/Groovy contributions have their own retained registration lifecycle. A rejected override may leave an earlier definition active, so seeing an old model does not prove your new file loaded.

Useful integration checks

  • Log the exact molecule ID and the view you queried: startup, running server, and local client views have different purposes.
  • Keep full stack metadata and NBT until lookup. A registry ID alone cannot carry qualified requirements.
  • Check the future before using newly registered geometry, and check export terminal results before opening files.
  • Store instance names, rule IDs, seed, and parameters with a successful network realization. Do not promise reproducibility after renaming paths.
  • Use private tests and a disposable development instance for capture; avoid modifying a player’s world or inventory for documentation examples.
