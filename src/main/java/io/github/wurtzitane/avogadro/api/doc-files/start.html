1. Install the basics

Use Avogadro with Minecraft 1.12.2, Cleanroom, and ModularUI. Java integrations target Java 25. Groovy examples need GroovyScript installed. The library starts without molecule definitions; the examples below add your own.

2. Add water

Java: call this method from your mod’s common initialization, with required-after:avogadro. Keep the returned future if later work depends on the new view.

Groovy: put the registration in your GroovyScript postInit script. Use the virtualized registry so script reload can replace its previous definitions.

JSON: save as config/avogadro/server/data/guide/molecules/water.json. The path supplies ID guide:water.

Java · method inside your host class; imports and full files below.

public static CompletableFuture<MoleculeView> register() {
    // Invoke once from your mod's common initialization. Reuse your mod ID as owner.
    return AvogadroApi.owner("guide").register(AvogadroApi.builder("guide:water")
            .name("Water").smiles("O").items("minecraft:water_bucket")
            .fluids("water").generateItem(true));
}

Groovy · same API; place methods in your script or client helper as described.

mods.avogadro.molecules.register('guide:water', [
    name: 'Water', smiles: 'O',
    items: ['minecraft:water_bucket'], fluids: ['water'], generate_item: true
])

JSON · one definition per file unless a different destination is shown.

{
  "name": "Water",
  "smiles": "O",
  "items": [
    "minecraft:water_bucket"
  ],
  "fluids": [
    "water"
  ],
  "generate_item": true
}
Expected result A water bucket gets a rotating H₂O preview. The generated sample uses the same definition. No new water-bucket item is created.
